Static personal portfolio for [Shihao Xing](https://github.com/Neroxsh), built for GitHub Pages.

## Local preview

Open `index.html` directly, or serve this directory with any static file server.

## Deployment

The recommended home is the public repository `Neroxsh/Neroxsh.github.io`. GitHub Pages will publish the repository at:

https://neroxsh.github.io/

No build step or server is required.
