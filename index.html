SQL EQUIVALENCE · REASONING MODEL

SQLEq-O1 面向 SQL 等价验证的轻量化推理模型

EMNLP 2026 Under Review
场景目标
面向 Text-to-SQL 评测、训练数据清洗和数据库回归测试中的 SQL 等价判断，解决执行式检查覆盖有限、形式化验证易超时、通用 LLM 成本高且推理不稳定的问题。
核心方法
构建 LeetCode 人工多解与 SynSQL 合成双轨数据，利用 VeriEQL 形式化标注并蒸馏验证式推理轨迹；采用 SFT warm-up + GRPO 可验证奖励训练 Qwen2.5/Qwen3 小模型。
效果产出
增强 hard-negative 覆盖并校准等价与不等价决策边界；Qwen2.5-Coder-1.5B 在 LeetCode-Hard GM 从 73.60 提升至 89.38，整体 AVG 提升至 83.08。

CROSS-DIALECT · BENCHMARK

UniQL 跨方言 Text-to-SQL 基准测试

EMNLP 2026 Under Review
场景目标
现有 Text-to-SQL 基准过度集中于 SQLite，难以评估真实异构数据库泛化；构建同一意图、Schema 和数据内容下的跨方言可执行评测基准。
核心方法
基于 BIRD dev 将 1,534 个自然语言问题扩展到 16 种 SQL 方言，完成数据库迁移、类型映射、SQLGlot/LLM 翻译、自反思修复、执行一致性校验和人工校验。
效果产出
形成 24,544 条可执行 SQL 标注，支持 MySQL、PostgreSQL、Oracle、Hive 等异构数据库下的横向评测，揭示当前模型跨方言泛化能力不足。

FORMAL VERIFICATION · FAILURE-AWARE ROUTING

FAR-SQL 面向 SQL 等价性判定的失效感知分层方法

NDBC 2026 Under Review
场景目标
解决 VeriEQL 确定结论可信但覆盖不足、本地小模型覆盖高但缺少形式化边界的问题，构建有限时延下形式化验证与任务适配模型协同的分层判定方法。
核心方法
基于历史 VeriEQL 日志建立验证收益画像并动态分配预算；保留形式化确定输出，对 timeout、unsupported、runtime error、conversion error 等非确定状态统一建模。
效果产出
将非确定状态路由到本地 SFT 模型或结构化状态约束分支；Calcite + Spider-DAIL 上 GM 达 83.98%，优于固定预算 VeriEQL 的 38.19% 与纯 SFT 的 76.20%。

MULTI-AGENT · SAFE-RAG

多智能体 SQL 验证与 Safe-RAG 系统

Agent System
场景目标
解决 SQL 生成与等价验证中检索材料不准、模型低置信输出和复杂语义差异难解释的问题，构建结构化检索增强与多 Agent 协同验证链路。
核心方法
基于 SQLGlot 抽取 AST 骨架并过滤字面量与别名，构建结构化向量检索库；解析模型 Logprobs 设置自适应阈值，在低置信场景下触发检索增强。
效果产出
基于 LangGraph 编排 SQL 生成、等价验证、反例搜索 Agent 并进行多源仲裁；检索准确率提升 40%，幻觉率降低 52%，提升复杂 SQL 验证鲁棒性。

EVALUATION · INFRASTRUCTURE

统一 SQL 评测基准框架

Evaluation Framework
场景目标
解决 NL2SQL、SQL 纠错、SQL 等价验证等任务评测标准割裂、流程重复建设和结果难以横向比较的问题，构建统一 SQL 评测与执行框架。
核心方法
设计通用任务抽象层，将输入构造、SQL 执行、结果比对、指标统计拆解为可复用环节；基于 Docker 构建标准化数据库环境，支持 MySQL、PostgreSQL、SQLite 自动切换。
效果产出
统一采用 EX 作为核心指标，支持多模型、多任务、多数据集横向对比；解耦任务定义与评测流水线，将新任务实验搭建周期由天级缩短至 小时级。
