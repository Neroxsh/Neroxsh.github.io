P.01
EMNLP 2026UNDER REVIEW

SQLEq-O1

面向 SQL 语义等价判定的轻量级强化推理框架，将形式化标签、推理蒸馏与可验证奖励统一到同一训练链路。

60KCoRE-SQL 89.38LeetCode-Hard GM 1.5BCompact Verifier
问题

执行测试无法证明等价，SMT 验证在复杂查询上易超时；通用大模型成本高，而轻量模型又容易依赖关键词和结构相似度形成偏置。

方法

双轨构造真实 LeetCode 多解与 SynSQL 合成难例，统一由 VeriEQL 形式化标注；蒸馏验证式 CoT，形成 6 万条类别均衡的 CoRE-SQL，再以 30% SFT Warm-up + 70% GRPO 和稀疏可验证奖励训练。

结果

Qwen2.5-Coder-1.5B 在 LeetCode-Hard 上由 34.88 GM 提升至 89.38，在域外 Calcite+Spider-DAIL 上由 44.58 提升至 76.77，兼顾小模型部署成本与困难样本判别能力。

P.02
EMNLP 2026UNDER REVIEW · ARXIV

UniQL

首个在相同自然语言意图、对齐 Schema 与数据内容下，系统评估 16 种 SQL 方言泛化能力的可执行基准。

16SQL Dialects 24,544Executable SQL 20.14%Best All-16
问题

现有 Text-to-SQL 基准高度集中于 SQLite，模型在单一方言上的成功无法说明其能否稳定迁移到 PostgreSQL、Oracle、Hive、Teradata 等真实数据库。

方法

将 BIRD Dev 的 1,534 个意图迁移到 16 种方言，组合数据库迁移、SQLGlot、LLM 翻译、三轮执行反馈自反思、规则演化和双人共识校验；比较时保留排序语义和重复项计数。

结果

形成 24,544 条人审可执行 SQL。最佳模型平均 EX 仅 54.63%，同一意图在 16 种方言全部正确的比例最高仅 20.14%，揭示 SQLite 评测掩盖的跨方言脆弱性。

P.03
NDBC 2026UNDER REVIEW

FAR-SQL

以“形式化优先、失效后补全”为原则，在有限预算内分离可信确定域与模型补全域。

83.98OOD GM 0%Undetermined 13.97sAverage
问题

VeriEQL 的确定输出可信，但复杂聚合、嵌套和方言函数会触发超时、不支持或转换异常；直接改用模型又会丢失形式化可信边界。

方法

从历史 VeriEQL 日志学习验证收益画像，按 SQL 结构动态分配预算；保留 equivalent/inequivalent 结论，将非确定状态归一化后路由至任务适配本地模型，并以 Self-Consistency@3 稳定补全。

结果

在 412 对 Calcite+Spider-DAIL 域外样本上达到 83.98 GM、0 未决率和约 14 秒平均耗时；相比 VeriEQL@60s 的 38.19 GM / 35 秒取得更优质量效率折中。

S.01

SQL EVALUATION INFRASTRUCTURE

统一 SQL 评测框架

面向 NL2SQL、SQL 纠错与等价验证的统一评测基础设施，将任务、模型、执行环境和评价指标彻底解耦。

任务 / 模型解耦 三数据库执行 统一 EX 与诊断
架构
以 Task Adapter 与 Model Adapter 解耦任务和模型；Input Builder、Prediction Parser、Execution Engine、Normalizer 与 Metric 均可独立替换。
方法
复用同一执行主干评测三类 SQL 任务，在 Docker 中标准化 MySQL、PostgreSQL 与 SQLite，并统一处理空值、顺序、重复行和执行异常。
结果
不同数据集与模型通过同一接口接入，统一产出执行准确率和错误诊断；新任务评测链路由天级缩短至小时级。

BANKING FINTECH · MULTI-AGENT

CreditRiskRobot

面向企业授信业务的智能审查工作台，把多格式材料理解、多 Agent 风险研判与可追溯报告生成串成完整业务闭环。

五类材料统一解析 多 Agent 风险协作 证据回链与自审计
架构

结果
